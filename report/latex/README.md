# 教师报告模板 LaTeX 版

[模板源文件](main.tex) · [PDF 预览](NPuzzle-template.pdf) · [空白正文及目录锚点](body.tex) · [版式参数](template.sty)

转换对象是本地 `teacher_reference/NPuzzle求解研究报告.docx`，不是已经完成的17页正式报告。原模板共3页：封面、目录、带页码1的空白正文页。LaTeX默认仍为这3页，没有新增可见正文或修改章节名称、编号、原有红色提示。原目录中的“.总结及展望”和“不在位将牌”照原文保留。

封面字体、文本位置、学期下划线、两行姓名学号栏和留白以本机Word只读导出的原模板PDF为参照；纸张尺寸595.3×841.9pt，左右页边距90pt，上下72pt。中文使用原宋体，封面英文使用原Arial Bold，页码和正文西文使用原Office主题的Calibri。没有套用通用的ctex封面或目录样式。

封面JPEG原尺寸650×328、72dpi，`assets/cover-original.jpeg`与DOCX内的原图逐字节一致。仅用`trim=2bp 2bp 2bp 2bp,clip`裁每边2像素，横向共裁0.615%、纵向共裁1.220%；未修改或重新生成校徽、校名，未把剩余内容放大补满。原始DOCX及已有正式报告未修改。

用户确认修复失效目录：保留蓝色目录标题、黑色条目、三级缩进、点引线、15.6pt行网格及4.1原两行的占位高度，错误书签文字和旧固定页码50改为真正的LaTeX目录链接及页码。34个条目对应`body.tex`中34个不可见占位锚点，默认都在空白正文第1页，所以目前目录均显示1。填写正文使占位移动到其他页面后，重新编译两次即可更新。原模板没有可用于对照的实际正文，故未自行设计可见章标题或新正文格式。

Windows安装XeLaTeX及上述原字体后，在项目根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File report/latex/build.ps1
```

或在本目录运行`xelatex main.tex`两次。推荐使用脚本：辅助文件及日志写入被忽略的`generated/latex-template-build/`，完成后只将预览PDF复制到本目录。脚本不读取教师文件、不依赖Word，不运行搜索。

填写封面只改`main.tex`中的六个信息宏；留空时保持原栏。原姓名栏较窄，长姓名可能超出原有空位，填写后需再次检查。正文写在`body.tex`对应占位之后；此模板不自动打印新增章节标题。

本轮验证记录见[qa.json](qa.json)。Word和XeLaTeX的字形栅格化有细小差异，保留版式不代表像素完全相同。原教师素材及许可边界继续见[第三方声明](../../THIRD_PARTY_NOTICES.md)。经用户授权，模板、必要图片、PDF和验证记录统一发布到现有私有仓库的main分支；原教师DOCX、参考目录及编译缓存不上传。
